## RULE 16 hard gates (fail if exceeded on new code)

| Check | Prefer (ideal) | **Fail if** | How counted | Tool |
|---|---|---:|---|---|
| Function LOC | ≤20 | **>30** | Inclusive AST span first `def` through last body line, blanks+docstring, excl decorators, nested counted separately | `verify_quality.py` |
| Class LOC | ≤120 | **>150** | Inclusive span of `class` body | same |
| Params | ≤3 | **>4** | Excl self/cls, kwonly counted, *args/**kwargs one each | same |
| Methods per class | ≤10 | **>15** | Defined on body only, incl `__init__` | same |
| Cyclomatic | ≤7 | **>10** | Radon base 1 +1 per if/elif/except/for/while/assert/with extra +1 per and/or +1 per comp if +1 ternary | `radon cc -s` |
| Cognitive | ≤10 | **>15** | Library default, nested scored separately | `cognitive-complexity` |
| Nesting | ≤3 | **>4** | Max ancestry if/loops/with/try/match, elif nested, siblings not | AST walker |
| Line coverage | ≥80% overall | **never decrease** vs baseline | `coverage.json` `percent_statements_covered` | `coverage run --branch` |
| Branch coverage | ≥75% overall | **never decrease** | `covered_branches/num_branches` | same |

**Exceptions:** Embedded JS inside Python string builders (`dom_highlight.build_highlight_js`) may be >30 LOC when excess is single JS/HTML literal; Python control flow around literal still CC≤10 nesting≤4. Compatibility facades re-export only may waive methods/class-LOC with override comment.

**Override format strict:** `quality-override: <metric>=<value> reason=<≥20 chars>` metric ∈ `loc, class-loc, params, methods, cc, cognitive, nesting, coverage, vulture, dup`. Reason must name constraint (wire format, generated JS, Qt slot signature), not convenience. One per metric per symbol.

## RULE 18 ideals (preferences, not fail lines, but require reason when exceeded)

| Element | Ideal | Sweet spot | Fail? |
|---|---|---:|---|
| **Function/method** | **4–20 lines** | ~8–12 | No, but must carry `# ideal-size: … reason=…` if outside |
| **Single file** | **150–300 lines** | ~200 | No, but reason required |
| **Module (dir)** | **5–15 files** cohesive | 7–10 | No |
| **Context file** (`docs/current/*`) | **60–200 lines** | ~120 | No, move detail to `archive/<date>-<topic>/` + link |

**Under 4 lines fine when:** name earns place (domain concept `check_stopped`, required hook, predicate used in several places). Not fine when body is one call re-hosted under meaningless name — metric-gaming §16.2 forbids.

**Over 20 usually means second responsibility hiding.** Fix via RULE 19.

**When exceed ideal:** `# ideal-size: 78 lines reason=single JS payload for probe; splitting string literal would break in-page agent contract` — reason must name constraint, never gaming.

## How to run full verification (copy-paste)

```bash
python tools/verify_quality.py --json > /tmp/gate.json
python tools/verify_quality.py --changed --allow-legacy
QT_QPA_PLATFORM=offscreen python -m coverage run --branch --source=app -m pytest tests -q
python -m coverage json -o /tmp/coverage.json
python - <<'PY'
import json
d=json.load(open('/tmp/coverage.json')); t=d['totals']
print(f"line {t['percent_statements_covered']:.1f}% branch {t['covered_branches']/t['num_branches']*100:.1f}%")
PY
npm run test:js
bash tools/pre_push_check.sh
```

All lanes must be green, 0 fails on changed files, global fails strictly decreasing.
